Sobre o Projeto AGPy

O AGPy é uma plataforma para Coleta, Integração, Análise e Visualização de dados geopolíticos e econômicos. O objetivo é facilitar o estudo das Relações Internacionais cruzando informações de diversas fontes em um só lugar.

Diferenciais

API Global (+210 Países)

Dados ao vivo de PIB, Inflação, Gasto Militar e Gini direto do Banco Mundial e RestCountries, cobrindo o mundo todo.

Base Local Especializada

Banco de dados próprio focado nas 10 maiores potências, detalhando alianças, IDH e Índice de Democracia.

Funcionalidades

Gráficos e Rankings

Classificação visual (Top 15 Mundo ou Base Local) para os indicadores.

Geografia Interativa

Mapas dinâmicos para entender a distribuição global de poder e economia.

Comparador de Países

Coloque duas nações lado a lado e compare seus perfis instantaneamente.

Exportação Rápida

Gere relatórios em PDF ou planilhas Excel com os dados pesquisados.
